# Godot Guild: Akademia Kodomancji

Edukacyjna gra fantasy do nauki informatyki, rozwijana w Godot 4.

## Automatyzacja
Projekt może korzystać z osobnego lokalnego schedulera. STOP jest twardym gate: nie uruchamia Godota, buildów ani zadań rozwojowych.

## Pierwszy vertical slice
Akademia Kodomancji i Krypta Algorytmów: pierwsza misja uczy pojęcia algorytmu poprzez mechanikę gry.

## Platformy
Windows + Android. Android może być dystrybuowany lokalnie jako APK; Google Play pozostaje opcjonalnym kanałem publikacji.
